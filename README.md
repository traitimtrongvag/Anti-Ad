# Anti-Ad

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)
[![Build](https://github.com/traitimtrongvag/Anti-Ad/actions/workflows/android.yml/badge.svg)](https://github.com/traitimtrongvag/Anti-Ad/actions/workflows/android.yml)

Anti-Ad helps you get past Spotify ads without reaching for your phone. When it spots an ad, it briefly interrupts Spotify and then tries to resume playback.

Anti-Ad is free and open source. It is an independent project and is not affiliated with Spotify.

## Getting started

Install Anti-Ad, then open it and follow the prompts:

1. Allow Notification Access so Anti-Ad can recognize Spotify ads.
2. Install and start [Shizuku](https://shizuku.rikka.app/), then authorize Anti-Ad. Shizuku is needed to interrupt Spotify.
3. Turn on Anti-Ad.

For fewer interruptions from your phone's power manager, allow unrestricted background use for Anti-Ad. Android settings vary by device, and some phones may still stop background apps.
